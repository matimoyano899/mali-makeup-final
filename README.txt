MALI MAKE UP - TIENDA PROFESIONAL
=================================

CÓMO ABRIR LA PÁGINA
--------------------
1. Descomprimí la carpeta.
2. Abrila en Visual Studio Code.
3. Hacé clic derecho sobre index.html.
4. Elegí “Open with Live Server”.

No necesita React, Node.js ni npm.

CÓMO CAMBIAR PRECIOS
--------------------
Abrí script.js y buscá la lista llamada “products”.
Cada producto tiene una línea como:

price: 8000,

Cambiá únicamente el número.

CÓMO CAMBIAR EL STOCK
---------------------
En el mismo producto vas a encontrar:

inStock: true

Usá true cuando haya stock y false cuando no haya stock.

También podés cambiar la etiqueta:

badge: "Nuevo"

CÓMO AGREGAR UN PRODUCTO
------------------------
Copiá uno de los objetos completos dentro de la lista products y cambiá:
- id
- name
- category
- categoryLabel
- price
- image
- description
- features
- badge
- inStock

Las categorías admitidas son:
- ojos
- mascaras (preparada, sin productos por ahora)
- labios
- kits
